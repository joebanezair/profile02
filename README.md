# Joebanezair Buatona — Professional Portfolio

A responsive, recruiter-focused portfolio website showcasing my experience in IT Support, Technical Support, QA, Customer Service, Sales, software development projects, education, certifications, and technical skills.

## Live-ready

This project is a static website and can be deployed for free using:

- GitHub Pages
- Vercel
- Netlify

## Tech

- HTML5
- CSS3
- Vanilla JavaScript
- No build step or dependencies required

## Sections

- Professional introduction
- Work experience
- Technical skills
- Featured GitHub projects
- Education
- Certifications
- Contact information

## Run locally

Open `index.html` directly in a browser, or run any simple static server.

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deployment — GitHub Pages

In GitHub, open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.

## Deployment — Vercel

Import this GitHub repository into Vercel and deploy with the default static-site settings.

## Updating the site

Most portfolio content is in `index.html`. Styling is in `styles.css` and small interactions are in `script.js`.
